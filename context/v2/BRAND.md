# Brand — the JVD block

Created 2026-10-25 for v2. The files are in `brand/` and generated by `brand/generate-logo.mjs` (`node context/v2/brand/generate-logo.mjs <out-dir>`). Edit the script, not the SVGs, so all variants stay consistent.

## Concept

v1's brand was the pixel text **"JVD."** with a green full stop. The v2 logo keeps that shape and makes it Minecraft:

- **The letters are blocks.** J, V and D are drawn on a pixel grid and extruded like the Minecraft title logo. The cream faces are the "stone"; the forest-green extrusion gives depth.
- **The letters are grass-capped.** The top row of each letter is grass, with a few drips into the second row, so each letter reads as terrain.
- **The full stop is a grass block.** The period becomes a small isometric grass block, the smallest building unit in the game. Jon builds worlds one block at a time.
- **The mark is the block, with initials on its faces.** For square spaces, an isometric grass block carries J on the left face, V on the right and D on top.

## Files

| File | Use |

| `jvd-mark.svg` | Square mark on #111e1a: app icon, avatar, OG image corner. Use at 48px or larger |
| `jvd-mark-transparent.svg` | Square mark without background |
| `jvd-favicon.svg` | Plain grass block, no letters. Favicon and anything under 48px |

## Rules

- Use on dark backgrounds (#0e1a17–#1c2e22, or the night sky). On light backgrounds the cream faces lose contrast; put the logo on a dark tile.
- Keep `shape-rendering="crispEdges"`. Scale by whole multiples where possible so the pixels stay sharp.
- Minimum wordmark height is 24px. Below that, use the favicon block.
- Pair the wordmark with "Jon Vincent Din" in ui-monospace when the full name is needed. Do not redraw the name inside the logo.
- In the header the logo is the editor entry. Give it the accessible name "Jon Vincent Din — editor sign-in".

## Motion

The intro builds the wordmark from falling voxels (STORYBOARD.md §0). The animation should be generated from the same pixel grid the script uses (export the cell list as JSON when V2-02 is built), so the animated and static logos always match.
