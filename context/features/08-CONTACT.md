# F08 — Contact

Route `#contact`. Preserve the book/correspondence composition, contact title/copy, contact links, fields and review interaction from public.js. Baseline does not send mail.

Owner edits title/copy and contact-link records. Only valid HTTP(S) or mailto destinations are allowed, with field-specific restrictions where appropriate.

Keep message review as the parity milestone. Real submission is a separate optional enhancement requiring a server function, input validation, rate limiting and a configured destination. Never claim “sent” when only a local preview or database draft exists.
