# Verification of suggested 3D tools

Checked: 2026-10-22 (UTC). Scope: original project/vendor documentation, not runtime installation, code security review or model-quality benchmarking. A documented capability is not a guarantee that it works with this client's version. Tool counts, provider lists and access conditions can change.

## Decision for this portfolio

**Install none of the eleven third-party entries now.** The current job is integration of existing assets, and the archive already contains a custom renderer, scene geometry and 48 GLBs. The useful addition is the repository's `jvd-3d-integration` workflow. It also accommodates future explicitly requested model creation.

This is a project-specific assessment, not a claim that the tools are bad. Use one external tool when a concrete task makes it worthwhile; do not install overlapping MCPs or entire skill packs preemptively. A skill supplies instructions, MCP supplies development access, and neither replaces the browser renderer or visual verification.

## Future model requests: choose by the job

1. **Minecraft-style item, book, symbol or simple character:** start with editable procedural voxel geometry using the existing asset conventions. Produce matching runtime scene data as well as GLB where required.
2. **Specific mesh repair, UVs, rigging or complex export:** inspect with local Blender/Python; use one Blender MCP bridge if interactive agent access is useful and available.
3. **Complex reference-driven organic model:** assess an image/text-to-3D provider such as Meshy or Tripo. Inspect current account access, costs, output quality and allowed uploads before starting. Plan a cleanup and browser-validation pass.
4. **An asset best sourced from a library:** search an appropriate provider and record the asset license/provenance. Do not replace approved assets simply because a similar model is available.

Stage new models separately with editable source, previews, geometry checks and provenance. Preserve existing assets and the approved React model. A generated GLB is not automatically compatible with the current procedural renderer. Make that conversion/integration explicit and validate lighting, scale, axes, edges, animation and input handling in the website.

## Installation threshold

Install a tool only after identifying the blocked task, confirming the exact official/community source and current client support, reviewing the needed configuration, and understanding any credentials, uploads or charges. Keep secrets outside the repository. Follow AGENTS.md for protected changes. Record what was actually used. This report intentionally contains no auto-start MCP configuration or bulk-install command.
